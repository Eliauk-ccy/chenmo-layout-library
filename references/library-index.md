# 尘墨排版模型库

全名：尘墨排版模型库
简称：尘墨排版库
英文标识：ChenMo Layout Library（CMLL）
当前版本：V1.1（建立于 2026-10-05；同日补齐脚本与提示词）

这是「尘墨notes」长期使用的公众号排版模型库。以后新增风格继续编号入库，不覆盖已有模型；除非用户明确要求修改某个模型，否则每个模型的设计规则和样张保持稳定。

## 调用方式

用户只要说出风格名或编号，助手就直接按对应模型排版，不再重新询问风格。例如：

- “用纸书散文风给我排版” → CM-01
- “用 CM-02 排这篇” → 杂志专栏风
- “用尘墨排版库里的温暖生活感排版” → CM-03
- “这篇用极简原稿风” → CM-04

如果用户只说“从排版库里选一个合适的”，助手根据题材推荐并说明理由；如果题材和模型明显不匹配，先提醒，不擅自换掉用户点名的模型。

每个模型目录包含：

- `STYLE.md`：设计规则、颜色、字体、组件和禁用事项
- `PROMPT.md`：可直接交给助手或排版人员使用的该风格提示词
- `sample.html`：可直接粘贴到公众号编辑器的同内容样张 HTML
- `preview.html`：可在浏览器中查看的样张预览页

## 具体脚本与提示词在哪里

模型库根目录：`workspace/chenmo-notes/layout-library/`

- 总提示词：`PROMPT.md`
- 可执行排版脚本：`scripts/build_article.mjs`
- 脚本使用说明：`scripts/README.md`
- 机器可读索引：`catalog.json`
- 全文实测输出：`tests/yangjiang-CM-01.html` 至 `tests/yangjiang-CM-04.html`

运行示例：

```bash
node scripts/build_article.mjs --input article.md --style CM-01 --output article.html --kicker 读书笔记 --subtitle 副标题
```

`--style` 可传 CM-01、纸书散文风或 paper-prose 等任一标识。脚本支持标题、章节、段落、引文、引用出处、小标题、图片、图片占位和加粗；复杂结构再按各模型 `PROMPT.md` 手工补齐。

## 通用排版规则

1. 正文内容以用户定稿为准，排版不得擅自删改原文；需要新增导读、编者按、看点或签名区时，使用不改变原意的结构文案，并向用户说明。
2. 所有样式必须内联，不使用外部 CSS、脚本、class 或 id。
3. 所有中文文字节点使用 `<span leaf="">` 包裹。
4. 不使用 `<div>`、`position: fixed/absolute/sticky`、`float`、`display: grid`、CSS 变量和媒体查询。
5. 成品必须运行公众号 HTML 校验，目标为 0 错误、0 警告。
6. 图片只替换模型中的图片占位位置，不改变图片原始比例和内容；图注按模型规则处理。
7. 同一篇文章只使用一个主模型，不随意混搭；用户明确要求混搭时，记录混搭来源和位置。

## 新增模型规则

新风格按顺序编号：CM-05、CM-06……每个新模型必须具备中文名、英文 ID、样张、预览、设计规则、专属提示词、适合题材和不适合题材；能脚本化的组件要同步加入 `scripts/build_article.mjs` 并跑全文校验。先做同内容样张给用户确认，用户确认喜欢后再正式入库。
