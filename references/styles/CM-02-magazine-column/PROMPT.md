# CM-02 杂志专栏风 · 排版提示词

把一篇文章排成“杂志专栏风”：像文化杂志的专栏页，标题醒目、层级清楚、有编辑部气质。

## 必须遵守

- 页面白色，正文 #222222，标题 #151515，主色酒红 #7d2434，浅底 #f7f3f1，线条 #e5e0dc。
- 使用无衬线字体，正文 16px、行高 1.85、两端对齐。
- 顶部先放 5px 酒红粗线，再放英文小字刊头“COLUMN · 栏目名”。
- 主标题左对齐、31px、粗体。副标题如有，灰色显示在标题下。
- 标题区底部放作者信息行：左侧“文 / 尘墨notes”，右侧为期数、日期或栏目信息，上下各一条细线。
- 第一段首字放大并染酒红色。引言或背景段可使用浅底 + 左侧酒红竖线块。
- 章节使用浅色大号数字水印，旁边放 PART 编号小字和中文章节名；原文只有数字时不编造章节名。
- 核心引文居中，上方放酒红色大引号，正文 20px 加粗。
- 引用出处右对齐、小字、灰色。
- 图片通栏呈现，图注使用“图注 / 内容”。
- 结尾用酒红元素收束，并写“—— 本篇完 ——”。

## 不要做

- 不用宋体正文、米白纸面、印章和圆角胶囊标签。
- 英文只作少量刊头和章节标签，不做科技产品风。
- 酒红只用于刊头、首字、引号、章节标签和关键锚点，不染大段正文。

变量：{{TITLE}}、{{SUBTITLE}}、{{KICKER}}、{{META}}、{{BODY_BLOCKS}}。正文结构映射以 sample.html 为准。
